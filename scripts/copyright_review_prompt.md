1. `EDITORIAL.md` の「著作権・引用のガバナンス（パクリ記事を出さないための決まり）」節を読む。
2. `git log origin/main..HEAD --name-only --oneline` で、この回に追加・変更された `content/articles/*.md` を確認する。無ければ「対象なし」で終了する。
3. 記事ごとに：
   a. 記事が**いちばん頼っている情報源1本だけ**（ふつうは `sources` の先頭の公式発表か作者のページ）を WebFetch で開き（開けなければ `https://r.jina.ai/<URL>`）、記事の各段落と見比べる。ほかの情報源は開かない（利用枠を抑えるため）。**段落の順番・論点の並び・言い回しが1つの情報源をなぞっている箇所**があれば、複数の情報源の事実を使って自分の構成・言葉で書き直す。事実（数字・日付・固有名詞）は変えない
   b. 引用カード（`:::quote`）の原文がそのページに一字一句あるか、1〜2文か。無ければ直すか外す
   c. 本文中の「」の発言に発言者・媒体があり、そのページが `sources` にあるか。報道機関の記事の文章そのものを「」で引いていたら自分の言葉に直す
   d. 引用（原文＋訳）が本文の2割を超えていたら減らす
   **Meta系ドメイン（facebook.com・fb.com・meta.com・ai.meta.com・threads.com・threads.net・instagram.com）は開かない。**
4. `python3 build.py` で、対象記事に「引用（原文＋訳）」「sources にない」「英語の原文」「「」引用」の注意が無いことを確かめる。
5. 直した記事だけ `git add` し、`fix(news): 引用・転載の校閲 <slug>` でコミットする。`git push` はしない。
