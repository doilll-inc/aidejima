フランスの建材大手Saint-Gobain（サンゴバン）が、Microsoftの研究開発向けAI「Microsoft Discovery」を使い、特許6万2,000件と論文の要旨4万4,000件から新しいセメント用の添加剤の候補を探したと、Microsoftが現地時間10月20日に公式サイトで紹介しました。研究者だけでやれば1年かかると見込んだ下調べが、数時間で終わったといいます。

## 何をしたか

Saint-Gobainは、1665年にベルサイユ宮殿の鏡を作るために生まれた会社で、いまは81カ国に16万1,000人の社員を抱え、ガラスや石こうボード、断熱材、セメントやコンクリートの添加剤を作っています。

狙ったのは、セメントを作るときに出るCO2を減らすことです。記事によると、セメントの生産は世界の年間CO2排出のおよそ7%を占めます。最も多く出るのは、石灰石を焼いて「クリンカー」と呼ばれる中間材料を作る工程です。Saint-Gobainの既存の添加剤は、このクリンカーの使用量を約20%減らせます。これを超える、CO2をさらに減らしつつセメントを強くし、できれば安くもなる成分を探しました。

## どう使ったか

Microsoft Discoveryは、研究者が複数のAI（エージェント）に指示して、文献を調べる・情報をつなぐ・仮説を立てる・実験を設計する・結果を分析する、といった研究の手順を進めさせる仕組みです。Microsoftは2025年の開発者会議で発表し、2026年6月の開発者会議で一般向けの提供を始めたと報じられています。

{{card:https://azure.microsoft.com/en-us/blog/transforming-rd-with-agentic-ai-introducing-microsoft-discovery/|Transforming R&D with agentic AI: Introducing Microsoft Discovery|Microsoft Azure Blog}}

Saint-Gobainは2026年3月、この仕組みを限定公開の段階から使い始めた最初期の顧客の1社です。担当したデジタル推進のプログラムマネージャー、モジュデ・ラストグー＝ルメートル氏のチームは、関係する特許と論文の要旨を集めてAIに読み込ませ、知識の土台を作りました。そこから絞り込みと分析を進め、試す価値のある新しい成分の候補をいくつか挙げています。

:::quote https://news.microsoft.com/source/emea/features/a-concrete-vision-saint-gobain-and-microsoft-discovery-build-for-the-future/ | Microsoft Source EMEA「A concrete vision」
> Without using this technology, it would have taken our researchers a year to create the knowledge base.
この技術を使わなければ、研究者が知識の土台を作るのに1年かかっていた。
:::

## 成果と、まだわからないこと

ラストグー＝ルメートル氏は、建設業界の外の分野まで探したことで、ふだんなら考えもしなかった分子が見つかったと話しています。ただし、それらの候補は求める性質があるかを実験で確かめている途中で、CO2をどれだけ減らせたかといった結果はまだ公表されていません。どの分野の、どんな物質かも明かされていません。

AIの使い道は研究だけではありません。記事によると、Saint-Gobainは建物の設計データを使って石こうボードを注文どおりに切る仕組みを作り、廃材を減らして施工にかかる時間を30%縮めました。2026年7月にはMicrosoftと包括的な提携を結び、9月には初めての最高AI責任者を置いています。フランスの研究拠点では、2027年1月から全社員がMicrosoftのAIアシスタント「Copilot」を使えるようにする予定です。

## 日本で真似するなら

研究開発の部門で同じことをするのに必要なのは、次の3つです。

- **読ませる文献を決める**: 自社の分野の特許と論文を、検索条件を決めてまとめて集めます。今回は建設業界の外まで広げたことが、意外な候補につながりました
- **AIに任せる範囲を決める**: 文献の整理と候補の洗い出しまでをAIに任せ、最後の判断と実験は研究者が受け持つ分け方です。Saint-Gobainの最高AI責任者アニカ・ハーゲン氏は、AIは目的ではなく、行きたいところへ行くための手段だと話しています
- **費用を確かめる**: Microsoft Discoveryの料金はこの記事では示されていません。導入を考えるなら、Microsoftの営業窓口に問い合わせる必要があります

## 日本のビジネスへの影響

- **使えるか**: Microsoft Discoveryは企業向けの仕組みで、日本での提供条件や料金は今回の記事では示されていません。まずは手元のCopilotやChatGPTの調べもの機能で、特許や論文の要旨の整理を試すこともできます
- **誰に効くか**: 素材・化学・食品・製薬など、新しい成分を探す研究開発部門の責任者と、特許調査を担う知財部門です。何万件もの文献を人が読む下調べの時間が、そのまま縮む可能性があります
- **今すぐやれること**: 自社の研究テーマを1つ選び、関係する特許の要旨を数百件まとめてAIに読ませ、「建設業界以外で似た働きをする物質は何か」のように分野をまたいだ問いを立ててみることです。調べものに強いAIの選び方は[リサーチAIのガイド](/best/research/)にまとめています
- **注意点**: 今回の事例は「下調べが速くなった」段階で、新しい添加剤ができたわけではありません。AIが挙げた候補は必ず実験で確かめる必要があります。また、未公開の研究データや出願前の発明を外部のAIに読ませるときは、契約上の扱いと情報の管理を先に確認しておく必要があります
